# Delivering the journal wall

Agreed November 25, 2026. The [interface direction](../DESIGN.md) owns the design decisions. These slices describe what a learner can try and which work to take on first. The [wall sketch](urban-plan-wall.png) sets the visual direction.

## First release

| Review unit | Slice | Learner outcome |
| --- | --- | --- |
| Wall and rooms | 1. Walk through the wall | Enter Practice, Read, Talk or Scrapbook from a distinct pinned object. Capture uses the notepad slip. Keyboard and narrow-screen access work from the first release. |
| Wall and rooms | 2. Open the shoebox | Reach the existing scrapbook table, Loose ends, sources, pictures, list and archive. |
| Wall and rooms | 9. Find the way home | Return from every room in one action. The tutor remains within reach. Following a source and going back preserves orientation. |
| Landmark offers | 3. Choose from today's offers | Each object offers something its destination can deliver, including on a fresh journal. Start with rules over current journal state. |
| Landmark offers | 4. Resume a passage | Read offers an unfinished bookmarked passage and opens there. With no such passage, it invites the learner to bring a reading. Finished pieces remain available in the Scrapbook. |
| Landmark offers | 5. Choose practice | The ticket reflects the current session. Only show a time or count that the session supports. |
| Landmark offers | 6. Pick up a conversation | Talk shows a recognizable conversation and offers a way to just talk. Existing threads suffice. |
| Landmark offers | 7. Revisit a recent piece | Enter the full scrapbook or go straight to the named piece. Archiving and deletion change what can be offered. |
| Practice | 10. Do one thing at a time | Enter from the ticket, answer, see the remaining work, and leave or finish. Preserve the ability to revisit misses. |

The first release keeps the existing capture behavior. **8. Show where a capture went** is on hold pending a clearer interaction. Projects can follow the wall independently.

Try the release with a few minutes and no specific plan. Recognize a bookmarked passage, read another paragraph, return home, and capture a word. Also try the ticket through an answer and exit, and open a recent piece from the shoebox. Check a fresh journal, a hidden or deleted piece, keyboard navigation, a narrow viewport, and enlarged text.

## Candidate slices after the first release

These are options for later review. Each has its own reason to build it.

| Slice | What the learner can try |
| --- | --- |
| 11. Return after a week | See an offer age out when the underlying invitation has expired. |
| 12. Peek on selection | Inspect an object by keyboard or touch before entering its room. |
| 13. Try the phone street | Move between shopfronts and capture comfortably one-handed. |
| 14. Re-pin an object | Select it, move it and find it there on return. |
| 15. See the wall change | Try time-of-day light or the rotation of one secondary offer. |
| 16. Recognize the two characters | Talk with the partner, reflect with the tutor and return to the exchange. |
| 17. Start the root conversation | Begin without naming a topic and return to the same conversation. First settle who greets the learner and how the tutor enters. |
| 18. Declare a project | Name an interest and pick it back up from the wall. |
| 19. Receive a project suggestion | Accept or pass over an invitation grounded in something previously discussed. |
| 20. Play a project scene | Return to a shared interest and use Chinese with the partner. |
| 21. Frame and debrief a scene | Try tutor-led framing and an optional debrief. Stay in the scene or skip the frame. |
| 22. Bring a scene into Practice | Practice an expression the partner actually explained or recast. |
| 23. Revisit a recent learning moment | Open a reminder tied to a real memory. Ambient display supplies no evidence of learning. |
| 24. See a trace on a piece | Find an occasion when a previously encountered expression appeared in the learner's own speech. |
| 25. Gather pieces | Choose a few pieces to practice together. |
| 26. Explore a rich item | Peek at its attachments and enter its reading, conversation or theme. |
